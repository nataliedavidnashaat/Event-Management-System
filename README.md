## About

A **GUI-based desktop application** for managing events end-to-end — from creation and scheduling to user registration and organization. Built with JavaFX for a clean, interactive interface backed by robust data validation to ensure system reliability.

---

## Features

| Feature | Description |
|---------|-------------|
| **Event Creation** | Create and configure events with full details |
| **User Registration** | Register and manage attendees per event |
| **Event Organization** | View, filter, and manage all events in one place |
| **Data Validation** | Input validation across all forms for reliability |
| **JavaFX GUI** | Clean, interactive interface with responsive controls |

---

## Tech Stack

- **Language:** Java
- **UI Framework:** JavaFX
- **Concepts:** Object-Oriented Programming, GUI design, data validation, event-driven programming

## How to Run

```bash
# Clone the repository
git clone https://github.com/nataliedavidnashaat/event-management-system.git
cd event-management-system

# Open in your IDE (IntelliJ / Eclipse / NetBeans)
# Make sure JavaFX SDK is configured

# Run Main.java
```

## Application Flow

```
Launch App
    ↓
Main Dashboard
    ├── Create New Event ──→ Fill Details ──→ Save
    ├── View All Events ──→ Filter / Search
    └── Register User  ──→ Select Event ──→ Confirm
```
